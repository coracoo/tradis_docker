# 社区版功能范围

社区版是独立运行的本地 Docker 管理面板，不连接 TRADIS 官方 Server。

## 可用功能

- 本机容器、镜像、卷、网络、端口管理，以及日志和容器终端。
- Compose 部署、配置编辑、历史记录与 Git 导入。
- 应用商店通过配置的 CDN 读取；教程只读取自行配置的 RSS，留空不加载内容；不提供 NAS 导购。
- 卷备份及 S3/WebDAV 存储、本地定时任务、通知与本地设置。
- 用户自配模型的导航识别和 Compose YAML 生成。

社区版不提供订阅许可、订单管理、官方教程服务、GitHub 应用、智能部署 Agent、
远程设备管理、应用保护或应用内自动更新。

## 数据和连接

使用独立安装目录、数据库、项目和备份路径，不与其他安装共享数据库。
Docker Registry、Git 仓库、备份存储、通知服务和模型服务由用户自行配置。
内容源不可用时不会回退到官方 Server。

## 安装和授权

纯本地安装使用 `client/docker-compose.community.yml` 和独立社区镜像，
更新时手动拉取镜像，也可固定发布镜像 digest。源码构建同样仅启用社区版功能。
README 的默认安装配置使用预构建完整版镜像，其可用能力以镜像和授权为准。
源码许可证见 LICENSE，贡献授权要求见 CONTRIBUTING.md。
